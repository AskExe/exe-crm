# Exe Foundry Bold — Self-hosted Fonts

Variable WOFF2 fonts for the Exe CRM frontend. Self-hosted for GDPR compliance
and Tauri webview reliability (no Google Fonts CDN).

## Fonts

| Font           | Role      | Weight range | Source                                                        |
|----------------|-----------|--------------|---------------------------------------------------------------|
| Epilogue       | Display   | 400–900      | https://fonts.google.com/specimen/Epilogue                    |
| Manrope        | Body      | 400–700      | https://fonts.google.com/specimen/Manrope                     |
| Space Grotesk  | Mono/Code | 400–700      | https://fonts.google.com/specimen/Space+Grotesk               |

## Downloaded from

WOFF2 variable font files sourced via fontsource CDN (jsdelivr):
- `Epilogue-Variable.woff2` — `fontsource/fonts/epilogue:vf@latest/latin-wght-normal.woff2`
- `Manrope-Variable.woff2` — `fontsource/fonts/manrope:vf@latest/latin-wght-normal.woff2`
- `SpaceGrotesk-Variable.woff2` — `fontsource/fonts/space-grotesk:vf@latest/latin-wght-normal.woff2`
